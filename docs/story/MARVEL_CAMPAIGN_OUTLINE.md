# Marvel: The Complete Multiversal Saga — campaign outline

Doomsday (50 scenes) → Secret Wars (100) → Ultimate Reset (10) = **160 scenes**.

Recorded 2026-10-17 from the project owner's outline.

## Canon status — read first

| Label | Meaning |
|---|---|
| **APPROVED** | Detailed user-approved script exists (dialogue, objectives, checkpoints). Safe to implement. |
| **ESTABLISHED** | The beat itself is agreed, but no detailed script is recorded here. |
| **PROPOSED** | Working reconstruction. **Not canon.** Must be reconciled with the original Story Reference Board before implementation. |

The original complete 160-scene Story Reference Board was not recovered. Do not implement a PROPOSED scene as locked
canon, and do not invent dialogue for a scene whose approved script isn't in the repository.

Implementation state lives in [`Development/STATUS.md`](../../Development/STATUS.md). In code, Doomsday scene *n* is
quest `wrmarvel:wr1_0nn` (see `MarvelIds.java`).
